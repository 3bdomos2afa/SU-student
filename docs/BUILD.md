## Release checklist

```sh
npx tsc --noEmit -p .
npm test                               # 137 tests
npm run preflight                      # package/lock match and required files
npm run test:server                    # SSO broker tests
npx expo-doctor                        # must be 20/20
CI=1 npx expo export --platform android
npm ci --dry-run --ignore-scripts
node scripts/build-preflight.cjs --eas
```

On EAS, the `eas-build-pre-install` hook runs the preflight, and `eas-build-post-install` prepares the fonts.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `expo doctor` fails with a patch mismatch | `npx expo install <pkg>@<expected>` for each package, then commit `package-lock.json` (fixed in 1.14.1) |
| Install fails on the phone | Uninstall the old app; 1.12.0+ is signed with a new key |
| No notifications with the app closed | Install a 1.15.0+ build, allow notifications, then use **Settings → Background notifications** to exempt SU+ and check the "last background check" line |

## Rules

- Do not run `expo prebuild` in place; `android/` and `ios/` are generated by EAS.
- Do not run `npm audit fix --force`.
- Keep `assets/fonts/` (Thmanyah and Froople) in the repo; the app bundles them.
- `media/` is repo-only and is excluded from EAS uploads by `.easignore`.
