# SU Student · 1.1.0

تطبيق مستقل غير رسمي لطلاب الجامعة، مبني بـ Expo / React Native على Android وiOS. هذه **نسخة مرشحة للاختبار** وليست إصدار متجر معتمدًا.

## ما تغير

- إزالة تكامل n8n وشاشة إعداداته. الدخول من صفحة UnicodeSIS داخل نافذة WebView، بعد موافقة صريحة على مخاطر HTTP.
- تصميم أخضر/عاجي خفيف مع الوضع الداكن، العربية والإنجليزية، وأيقونة كتاب/قبعة أصلية.
- إصلاح خطأ قابل لإعادة الإنتاج في التبويبات: Expo Router 58 يمرر `navigateToTab` و`emitter` إلى الشريط المخصص، وليس `navigation`. أُزيل تحويل النوع الذي كان يخفي الخطأ.
- إلغاء مؤثرات الزجاج الأصلية والحركة المستمرة، مع معالجة أخطاء العرض وحالات التخزين/الشبكة وانتهاء الجلسة.
- حفظ الجلسة والبيانات المدعومة مشفرة على الجهاز، وتحديث يدوي/سحب للتحديث، وبانر انقطاع/عودة الاتصال.
- خطة IT بها 49 مادة ومتطلبات، مسودة تسجيل وحاسبة معدل **تقديرية**، مهام ومؤقت تركيز محلي.
- المؤقت يتدارك وقت الخلفية؛ يتوقف عند مغادرة صفحته ولا يرسل إشعارات خلفية.

## التشغيل والبناء

Node 24 وnpm:

```sh
npm ci
npm test
npm run typecheck
npx expo-doctor
npx expo start
```

نافذة تسجيل الدخول مخصصة لـ Android/iOS. نسخة الويب للمراجعة البصرية والأدوات المحلية؛ بياناتها الخاصة في الذاكرة فقط. لا تعتبر اختبارًا للجلسة الأصلية أو Keychain/Keystore.

لإنشاء APK اختبار جديد:

```sh
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview
```

للإنتاج بعد اجتياز اختبارات الجهاز:

```sh
npx eas-cli@latest build -p android --profile production
npx eas-cli@latest build -p ios --profile production
```

معرّفات المشروع الموجودة محفوظة: `@su_student/su-student` وحزمة `com.unicodesis.student`. يجب أن يملك حساب Expo صلاحية المشروع. لم تُرفق مفاتيح توقيع أو بيانات دخول. **التحديث يحتاج binary جديد** بسبب إضافة WebView/تغييرات native؛ لا يكفي OTA وحده. البناء الإنتاجي Android يعطي AAB، بينما profile preview يعطي APK. iOS يحتاج حساب Apple وإعداد توقيع مناسب.

## الخطوط المرفوعة من المستخدم

النسخة المحلية التي راجعناها تستخدم **Thmanyah Sans** للعربية و**Froople** للعناوين الإنجليزية، مع Inter للنصوص الإنجليزية لسهولة القراءة.

**ملفات الخطوط التجارية الخام ليست داخل هذا الأرشيف ولا Git.** ترخيص Thmanyah المرفق يسمح بتضمين الخط في تطبيق مجمّع ولا يسمح بإعادة توزيع ملف الخط منفصلًا. لم يوجد ترخيص داخل ملف Froople؛ تحقق من حق تضمينه قبل النشر. ترخيص MIT الخاص بكود المشروع لا يشمل هذه الخطوط.

`npm ci` يولّد `src/lib/fonts.ts` تلقائيًا: Cairo/Inter إن لم يجد الخطوط، أو الخطوط المطلوبة إن وجدها. لإضافتها من أرشيفاتك الأصلية:

```sh
mkdir -p assets/fonts
unzip -p /path/to/Thmanyah-Font-Family.zip 'thmanyah typeface/thmanyahsans/otf/thmanyahsans-Regular.otf' > assets/fonts/ThmanyahSans-Regular.otf
unzip -p /path/to/Thmanyah-Font-Family.zip 'thmanyah typeface/thmanyahsans/otf/thmanyahsans-Bold.otf' > assets/fonts/ThmanyahSans-Bold.otf
unzip -p '/path/to/Froople Font.zip' Froople.ttf > assets/fonts/Froople.ttf
node scripts/prepare-fonts.cjs
```

EAS يستخدم `.gitignore` لتحديد محتويات الرفع، لذلك يبني افتراضيًا بالخطوط البديلة حتى لو كانت الخطوط التجارية موجودة عندك. **بعد التحقق من أن الترخيص يسمح بمعالجتها في بيئة البناء المختارة**، يمكنك إنشاء `.easignore` خاص بك بنسخ `.gitignore` وحذف السطرين `assets/fonts/*.otf` و`assets/fonts/Froople.ttf` منه فقط. اتركهما في `.gitignore` حتى لا تدخلا Git. حينها ستدخل الخطوط في سياق بناء EAS الخاص بك ويختارها سكريبت postinstall. نفس اعتبار حزمة المصدر ينطبق على EAS local build. لا تنشر سياق البناء الخام أو أرشيف الخطوط أو web export يحتويها للعامة. يوجد سكريبت اختياري `scripts/eas-fonts.cjs` لا ينشئ سياسة الرفع إلا بتأكيد صريح للحقوق، ولا يستبدل ملفًا موجودًا.

## بيانات الجامعة وحدود الربط

المسارات مستخرجة من عميل JavaScript العام للجامعة. لم نختبرها بحساب طالب حقيقي، وقد تتغير أو تختلف بنية الرد حسب الحساب.

11 قراءة مدعومة في `src/lib/portal.ts`:
الملف الأكاديمي، البيانات الشخصية، المواد الحالية، الجدول، نسب الغياب، الإنذارات، السجل الدراسي، السنوات الدراسية، فترة التسجيل، الإرشاد، والتربية العسكرية.

تستخدم الطلبات `StudentID` الموجود في جلسة الطالب بعد دخوله. قراءة السجل الدراسي تستخدم POST كما في الموقع الأصلي مع `SemesterYearId=0`؛ لم يُفترض أن هذا يمثل تاريخ كل الفصول. تُعرض الحقول كما أرجعتها الجامعة. لا يوجد تسجيل مواد، دفع رسوم، تغيير بيانات أو إرسال استبيانات آلي. الخدمات غير المربوطة توجه إلى الموقع الرسمي، وقد تتطلب دخولًا منفصلًا هناك؛ لا نزعم سحب كل بيانات الحساب.

الخطة محلية لتخصص IT، وليست مستوردة من ملف الطالب. مجموع المواد المذكورة 143 ساعة مقابل هدف برنامج 144؛ لا تُخترع مادة لسد الفرق. حاسبة المعدل تستخدم سلمًا شائعًا من 4 نقاط للتقدير وليست سياسة جامعية مؤكدة.

## الخصوصية والأمان

- البوابة `http://unicodesis.su.edu.eg` والـ API على منفذ 150 يستخدمان HTTP غير مشفر. كلمة المرور والرمز والبيانات معرضة لاعتراض الشبكة. **التشفير على الجهاز لا يحمي النقل**؛ يلزم HTTPS من الجامعة قبل توصية بتوزيع واسع.
- لا يقرأ كود التطبيق كلمة السر. تُكتب في موقع الجامعة؛ جسر WebView يلتقط حقول الجلسة المطلوبة فقط.
- الجلسة والبيانات تُحفظ بـ AES-GCM مع مفتاح عشوائي في Keychain/Keystore؛ بيانات الويب الخاصة ذاكرة فقط. البيانات مرتبطة بحساب، والخروج يحذف cache وأدوات ذلك الحساب.
- الاستثناء الخاص بـ cleartext محصور بنطاق الجامعة، مع منع التنقل خارج نطاق صفحة الدخول ومنع تحويلات طلبات API.
- WebView في وضع incognito. قفل البصمة اختياري؛ تم اختباره منطقيًا فقط، لا على جهاز.
- لا telemetry ولا رفع بيانات الطالب إلى خادم التطبيق. ملفات Git/الأرشيف لا تحتوي مفاتيح أو كلمات سر.
- إعادة الدخول بعد انتهاء جلسة الجامعة مطلوبة. التطبيق لا يستطيع إبقاء جلسة ألغاها الخادم.

## التحقق

راجع `TESTING.md` لنتائج الاختبارات وحدودها وخطوات اختبار جهاز قبل الإصدار. نجاح TypeScript/Metro/prebuild ليس إثباتًا لنجاح بناء Gradle/Xcode أو اختفاء كل حالات القفل.

تمت مراجعة `npm audit`: توجد تحذيرات high في أدوات Expo الخاصة بالبناء (`node-forge` و`zod` والاعتماديات المرتبطة بها). لم نفرض ترقية Zod إلى major مختلف أو downgrade لـExpo لإسكات التحذير. أعد المراجعة قبل إصدار متجر، وحدّث الأدوات بإصدارات متوافقة عند توفرها.
